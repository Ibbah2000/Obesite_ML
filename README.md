
# Obesite_ML

Projet de classification supervisée des niveaux d'obésité.

## Dataset
UCI - Estimation of Obesity Levels
2111 individus, 14 variables explicatives, 7 classes

## Méthodes utilisées
- Logit ordonné
- Random Forest
- Arbre de décision
- LDA / QDA / SVM
